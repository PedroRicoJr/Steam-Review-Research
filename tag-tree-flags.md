## Tie-broken

| Pair | Kept | Reasoning |
|---|---|---|
| `art.atmosphere` vs `narrative.world-and-setting` | Both | Atmosphere is the **felt mood**; world-and-setting is **what the fiction is**. A review can praise the mood while disliking the world. Overlap is real but the two are separable. |
| `game-design.difficulty-tuning` vs `game-design.power-balance` | Both | Renamed from `balance` for exactly this reason. Difficulty is *how hard the game is*; power-balance is *whether the options are equally strong*. A game can be well-tuned and badly balanced. |
| `community.player-behaviour` vs `community.culture` | Both | Behaviour is **conduct** — toxicity, griefing, quitting. Culture is **shared identity** — catchphrases, rituals. Deep Rock has excellent both; a game can have polite players and no culture at all. |
| `live-ops.abandonment` vs `community.developer-communication` | Both | Abandonment is **the work stopping**. Communication is **what the studio says**. A studio can go silent while still shipping, or talk constantly while shipping nothing. |
| `engineering.bugs` vs `production.launch-state` | Both | A present-tense defect is a bug. A judgement about the condition it shipped in is launch-state. Recorded as a tiebreak in `tag-tree.md`. |

## How to use this file

When a new tag is proposed and something close already exists:

1. Can one absorb the other without losing a real distinction? → **fold up**, record in `tag-tree-rejected.md`.
2. Are they genuinely two facts? → **keep both**, record the split here so it is never re-argued.
3. Cannot tell? → **⏳ Waiting on Rico.** Do not guess; a wrong split is expensive to unwind once
   thousands of bullets are tagged against it.
