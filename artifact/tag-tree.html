How to read a row. The bottom tag is the mode — how a thing went right or wrong. Every mode declares its own direction, so good or bad comes from the tag itself and never from whether the reviewer gave a thumbs up.

The number on the right is how many times it was actually used across every review read so far. A 0 means the tag exists because the tree needed the other half of a pair, or because a different game will need it. Those are the ones most worth arguing about — nothing has tested them.

The naming rule: a tag name must read its own direction with no lookup. .world-ignores-you, not .static-scenery. Name the complaint, not the property. If a name below fails that test, it is wrong and I want to know.
